# AbilityX Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the two approved AbilityX pages in a new Next.js App Router app with Tailwind and local typed content objects, using the design handoff for page structure and the AbilityX design system for tokens.

**Architecture:** Create a small App Router marketing site with two routes: `/` and `/events/1.0`. Keep page composition server-rendered, isolate the home-page CTA form success toggles in a client component, and store repeatable content in typed local modules that can later be replaced with Payload fetches.

**Tech Stack:** Next.js App Router, React, TypeScript, Tailwind CSS, `next/font`, ESLint

---

```tsx
// components/ui/pill-button.tsx
import Link from 'next/link';
import { cn } from '@/lib/cn';

type PillButtonProps = {
  href: string;
  children: React.ReactNode;
  variant?: 'primary' | 'outline' | 'ghost' | 'nav-active' | 'nav-idle';
  className?: string;
};

const variants = {
  primary: 'bg-brand-red text-white hover:bg-brand-red-dark',
  outline: 'border border-white/30 bg-transparent text-white hover:bg-white/10',
  ghost: 'border border-brand-border-strong bg-transparent text-brand-black hover:bg-brand-subtle',
  'nav-active': 'bg-brand-red-soft text-brand-red',
  'nav-idle': 'text-brand-black hover:bg-brand-subtle',
};

export function PillButton({ href, children, variant = 'primary', className }: PillButtonProps) {
  return (
    <Link
      href={href}
      className={cn(
        'inline-flex items-center justify-center rounded-full px-5 py-3 text-sm font-semibold transition-colors duration-150 ease-in-out',
        variants[variant],
        className,
      )}
    >
      {children}
    </Link>
  );
}
```
