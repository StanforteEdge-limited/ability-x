# AbilityX CMS: Editor Guide

The website has three things you can edit yourself: **Speakers**, **Schedule** and **Blog**.
Everything else (homepage text, About, Partner, the AbilityX 2025 page, navigation) is changed by the web team.

## Signing in

1. Go to **https://ability-x.org/admin** and click **Sign in**.
2. First time? An admin sends you an invite by email. Open it and set up a passkey (fingerprint, face or device PIN).
3. Lost your passkey? Use **Email me a sign-in link** on the sign-in page.

Published changes appear on the live site within about a minute.

## Speakers

Speakers → **New Speaker**.

| Field | What to enter |
|---|---|
| Full name | e.g. `Temi Dalley` |
| Role / title | Job title only, e.g. `Group Executive, Human Capital` |
| Organisation | e.g. `Sterling Financial Holdings` |
| Photo | Square photos look best (at least 600 × 600 px). Add alt text: `Portrait of <name>.` |
| Session title | **Only once it is confirmed.** Leave empty until then. |
| Edition | `2026` for this year. `2025` speakers appear on the AbilityX 2025 page. |
| Sort order | Lower numbers show first. Use steps of 10 (10, 20, 30…) so you can slot people in later. |

- 2026 speakers appear on the homepage. Until there is at least one, the homepage says "Speakers will be announced soon."
- Add a speaker only once they are approved for public announcement. Save as a **draft** until then.
- A speaker without a photo shows their initials.

## Schedule

Schedule → **New Session**.

| Field | What to enter |
|---|---|
| Title | e.g. `Opening keynote` |
| Session type | Pick from the list (Keynote, Panel, Break…) |
| Start time | **24-hour time with a colon**, e.g. `09:00`, `13:30` |
| End time | Same format. Optional. |
| Location | e.g. `Main Hall` |
| Description | One or two sentences |
| Speakers | Pick from the Speakers list. Add the speaker there first if they're missing. |

The schedule page sorts sessions by start time. A time typed any other way (e.g. `9am`) still shows, but at the end of the list.
Until a session is published, the Schedule page says "The full programme will be published soon."

## Blog

Blog Posts → **New Blog Post**: title, excerpt (one or two sentences for the blog list and social shares), featured image, body, and a category.

- **Publish** makes it live now. **Schedule** picks a future date and time; the post goes live by itself.
- The date shown on the post is its publish date. You can change it in the post's publish settings.
- Read time is worked out automatically.

## Images

Upload in the Media library or straight from a field. Always fill in **alt text**: describe the picture for people who can't see it.
