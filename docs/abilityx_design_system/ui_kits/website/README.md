# AbilityX Website UI Kit

A high-fidelity, click-through prototype of the AbilityX event website.

## Screens / Pages
- **Home** — Hero (dark), Speakers grid, Agenda
- **Speakers** — Full speaker listing with bios
- **Agenda** — Day-toggle session schedule
- **Register** — 2-step registration form with success state

## Components
| File | Description |
|---|---|
| `NavBar.jsx` | Fixed top nav with page links + CTA |
| `HeroSection.jsx` | Full-bleed dark hero with stats |
| `SpeakersSection.jsx` | Speaker card grid with hover states |
| `AgendaSection.jsx` | Day-tab session schedule |
| `RegisterSection.jsx` | 2-step registration form |
| `index.html` | Main prototype shell |

## Design Width
1440px desktop. All padding uses 80px gutters.

## Fonts
- **Nunito** (Black 900, ExtraBold 800, Bold 700) — display/headings
- **DM Sans** (Regular 400, Medium 500, SemiBold 600, Bold 700) — body/UI

## Key Colors
- `#CC0000` — Brand red (CTAs, accents, overlines)
- `#0D0D0D` — Brand black (hero bg, nav text)
- `#FFFFFF` — White (card backgrounds, text on dark)
